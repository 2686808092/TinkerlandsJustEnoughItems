# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · **Deutsch** · [Español](README.es.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Im Inventar von Tinkerlands lassen sich Gegenstände, Rezepte, Verwendungen und Bezugsquellen nachschlagen. Die Gegenstandsliste erscheint links.

## Installation

Lade `Just_Enough_Items_1.7.2.zip` unter [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) herunter. Lege die ZIP-Datei unverändert in den Ordner `mods` des Spiels und starte es neu. Entferne beim Update die alte JEI-ZIP.

Die Mod-Oberfläche ist auf vereinfachtem Chinesisch und Englisch verfügbar. Die Namen der Gegenstände und Werkstationen folgen der aktuellen Spielsprache.

## Standardsteuerung

| Aktion | Eingabe |
| --- | --- |
| Rezepte oder Bezugsquellen ansehen | Linksklick in der Liste oder den Gegenstand anvisieren und `R` drücken. |
| Verwendungen ansehen | Rechtsklick in der Liste oder den Gegenstand anvisieren und `U` drücken. |
| Suchen und blättern | `Ctrl+F` aktiviert die Suche. Mausrad, Pfeile oder `Page Up` / `Page Down` blättern. |
| Liste ein- oder ausblenden | Bei geöffnetem Inventar `Ctrl+O` drücken. Die Auswahl wird gespeichert. |
| Details schließen oder Einstellungen öffnen | `Esc` schließt die Details. Das Werkzeugsymbol neben der Suche öffnet die Einstellungen. |

## Rezepte und Bezugsquellen

- Die Mod zeigt Handwerks-, Koch- und 3×3-Transmutationsrezepte. Ein Klick auf eine Zutat öffnet deren Eintrag. Ein Klick auf den Namen der Werkstation zeigt deren Rezepte.
- Unter Verwendungen stehen Rezepte, die den Gegenstand benötigen. Bekannte Quellen sind Beute, Läden, Aufgaben, Aufträge, Angeln, Truhen und Sammeln.
- Eine Suche wie `#Blueprints` findet Rezeptpläne. `R` zeigt bekannte Quellen und `U` das freigeschaltete Rezept.

## Suche

Suche nach Gegenstandsnamen oder nutze Pinyin für chinesische Namen. `#Accessories` filtert Accessoires, `@vanilla` Gegenstände des Grundspiels.

`$text` durchsucht Beschreibungen, `%category` filtert Kategorien. Anführungszeichen umschließen Wortgruppen, `-word` schließt Wörter aus. Ein Leerzeichen kombiniert Bedingungen, ein senkrechter Strich erlaubt Alternativen. Im Entwicklermodus sind ID-Suchen wie `id:144` verfügbar.

## Einstellungen, Cheats und Entwicklermodus

Die automatische Pause im Einzelspielermodus ist standardmäßig aktiv und lässt sich abschalten. Im Mehrspielermodus läuft das Spiel weiter.

Mit `Strg + Linksklick` auf das Werkzeugsymbol schaltest du den Cheatmodus um. Ein Klick auf einen Gegenstand gibt ein Exemplar, mit Umschalttaste einen Stapel. Mit aktiviertem Entwicklermodus lassen sich auch vom Spiel erzeugbare versteckte Gegenstände erhalten.
