# Just Enough Items for Tinkerlands

Consulte itens, receitas, usos e formas de obtenção no inventário de Tinkerlands. A lista de itens fica à esquerda.

## Instalação

Baixe `Just_Enough_Items_1.7.0.zip` em [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest). Coloque o ZIP sem extrair na pasta `mods` do jogo e reinicie. Ao atualizar, remova o ZIP anterior do JEI.

A interface do mod está disponível em chinês simplificado e inglês. Os nomes dos itens e das estações seguem o idioma do jogo.

## Controles padrão

| Ação | Comando |
| --- | --- |
| Ver receitas ou formas de obtenção | Clique com o botão esquerdo em um item da lista ou passe o cursor e pressione `R`. |
| Ver usos | Clique com o botão direito em um item da lista ou passe o cursor e pressione `U`. |
| Buscar e trocar de página | `Ctrl+F` ativa a busca. Use a roda do mouse, as setas ou `Page Up` / `Page Down` para trocar de página. |
| Mostrar ou ocultar a lista | Pressione `Ctrl+O` com o inventário aberto. O mod salva a escolha. |
| Fechar detalhes ou abrir configurações | Pressione `Esc` para fechar os detalhes. Clique no ícone de ferramenta ao lado da busca para abrir as configurações. |

## Receitas e obtenção

- Consulte receitas de fabricação, culinária e transmutação na grade 3×3. Clique em um ingrediente para abrir sua ficha ou no nome de uma estação para ver suas receitas.
- A aba de usos exibe receitas que consomem o item. Entre as fontes conhecidas estão despojos, lojas, missões, contratos, pesca, baús e coleta.
- Encontre projetos de receitas com uma busca como `#Blueprints`. Pressione `R` para ver fontes conhecidas e `U` para ver a receita desbloqueada.

## Busca

Busque pelo nome do item ou use pinyin para nomes em chinês. Use `#Accessories` para acessórios e `@vanilla` para itens do jogo base.

`$text` pesquisa nas descrições e `%category` filtra categorias. Use aspas para expressões e `-word` para excluir palavras. Um espaço combina filtros e a barra vertical indica alternativas. O modo desenvolvedor permite buscas por ID como `id:144`.

## Configurações, trapaças e modo desenvolvedor

A pausa automática vem ativada no modo solo e pode ser desativada nas configurações. No multijogador a partida continua.

Use `Ctrl + clique esquerdo` no ícone de ferramenta para alternar o modo de trapaça. Clique em um item para obter uma unidade, ou segure Shift para obter uma pilha. Com o modo desenvolvedor também ativo, você pode obter itens ocultos que o jogo consegue gerar.
