# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md) · **Русский**

Просматривайте предметы, рецепты, способы применения и источники получения прямо в инвентаре Tinkerlands. Список предметов появляется слева.

## Установка

Скачайте `Just_Enough_Items_1.7.4.zip` из раздела [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest). Поместите ZIP без распаковки в папку `mods` и перезапустите игру. При обновлении удалите старый архив JEI.

Интерфейс мода доступен на упрощённом китайском и английском. Названия предметов и рабочих станций соответствуют текущему языку игры.

## Управление по умолчанию

| Действие | Управление |
| --- | --- |
| Посмотреть рецепты или источники | Щёлкните предмет в списке левой кнопкой или наведите на него курсор и нажмите `R`. |
| Посмотреть применение | Щёлкните предмет в списке правой кнопкой или наведите на него курсор и нажмите `U`. |
| Искать и листать | `Ctrl+F` ставит курсор в строку поиска. Для смены страницы используйте колесо мыши, стрелки или `Page Up` / `Page Down`. |
| Показать или скрыть список | Нажмите `Ctrl+O` при открытом инвентаре. Мод запоминает выбор. |
| Закрыть карточку или открыть настройки | `Esc` закрывает карточку. Значок инструмента рядом с поиском открывает настройки. |

## Рецепты и источники

- Доступны рецепты изготовления, готовки и трансмутации в сетке 3×3. Щёлкните ингредиент, чтобы открыть его карточку, или название рабочей станции, чтобы просмотреть её рецепты.
- В разделе применения показываются рецепты с выбранным предметом. Известные источники включают добычу с существ, магазины, задания, контракты, рыбалку, сундуки и сбор ресурсов.
- Запросом вроде `#Blueprints` можно найти чертежи рецептов. `R` показывает известные источники, а `U` — открываемый рецепт.

## Поиск

Ищите по названию предмета, а для китайских названий можно использовать пиньинь. `#Accessories` находит аксессуары, а `@vanilla` — предметы базовой игры.

`$text` ищет по описанию, `%category` фильтрует по категории. Кавычки объединяют слова во фразу, а `-word` исключает слово. Пробел сочетает условия, вертикальная черта допускает любое из них. Режим разработчика позволяет искать по ID, например `id:144`.

## Настройки, читы и режим разработчика

В одиночной игре автопауза включена по умолчанию и отключается в настройках. Сетевая игра продолжается.

Используйте `Ctrl + щелчок левой кнопкой` по значку инструмента для переключения чит-режима. Щелчок по предмету выдаёт один предмет, а щелчок с Shift — стопку. Если также включить режим разработчика, можно получить скрытые предметы, которые умеет создавать игра.
