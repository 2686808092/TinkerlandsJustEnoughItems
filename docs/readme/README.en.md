# Just Enough Items for Tinkerlands

Browse items, recipes, uses, and acquisition sources inside the Tinkerlands inventory. The item list opens on the left.

## Installation

Download `Just_Enough_Items_1.7.0.zip` from [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest). Put the ZIP directly in the game's `mods` folder and restart. Remove the older JEI ZIP when upgrading.

The mod interface is available in Simplified Chinese and English. Item and crafting station names follow the game's current language.

## Default controls

| Action | Input |
| --- | --- |
| View recipes or sources | Left-click a list item, or hover and press `R`. |
| View uses | Right-click a list item, or hover and press `U`. |
| Search and browse | `Ctrl+F` focuses search. Use the mouse wheel, the arrows, or `Page Up` / `Page Down` to turn pages. |
| Toggle the list | Press `Ctrl+O` with the inventory open. The mod remembers your choice. |
| Close details or open settings | Press `Esc` to close details. Click the tool icon beside search for settings. |

## Recipes and sources

- Look up crafting, cooking, and 3×3 Transmutation Cube recipes. Click an ingredient to inspect it, or a crafting station name to browse its recipes.
- The Uses view shows recipes that consume the selected item. Known sources include drops, shops, quests, contracts, fishing, chests, and gathering.
- Find recipe blueprints with a query like `#Blueprints`. Press `R` for recognized sources and `U` for the recipe it unlocks.

## Search

Search by item name, or by pinyin for Chinese names. Use `#Accessories` for accessories and `@vanilla` for base-game items.

Use `$text` for descriptions, `%category` for categories, quotes for phrases, and `-word` to exclude a word. A space combines conditions, while a vertical bar matches either term. Developer mode enables item ID queries such as `id:144`.

## Settings, cheats, and developer mode

Single-player auto-pause is on by default and can be disabled in settings. Multiplayer continues running.

`Ctrl-click` the tool icon to toggle cheat mode. Click a listed item for one item or Shift-click for a stack. With developer mode enabled too, you can obtain hidden items that the game can generate.
