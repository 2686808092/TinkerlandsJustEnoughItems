# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · **한국어** · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Tinkerlands 인벤토리에서 아이템, 제작법, 용도, 획득처를 찾아볼 수 있는 모드입니다. 아이템 목록은 화면 왼쪽에 표시됩니다.

## 설치

[GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest)에서 `Just_Enough_Items_1.7.3.zip`을 내려받아 압축을 풀지 않고 게임의 `mods` 폴더에 넣은 뒤 게임을 다시 실행하세요. 업데이트할 때는 이전 JEI ZIP을 제거하세요.

모드 인터페이스는 중국어 간체와 영어를 제공합니다. 아이템과 제작대 이름은 게임에 설정된 언어를 따릅니다.

## 기본 조작

| 동작 | 입력 |
| --- | --- |
| 제작법 또는 획득처 보기 | 목록의 아이템을 왼쪽 클릭하거나 커서를 올리고 `R`을 누릅니다. |
| 용도 보기 | 목록의 아이템을 오른쪽 클릭하거나 커서를 올리고 `U`를 누릅니다. |
| 검색과 페이지 이동 | `Ctrl+F`로 검색창에 초점을 맞춥니다. 휠, 화살표 또는 `Page Up` / `Page Down`로 페이지를 넘깁니다. |
| 목록 표시 또는 숨기기 | 인벤토리를 열고 `Ctrl+O`를 누릅니다. 마지막 상태가 저장됩니다. |
| 상세 정보 닫기 또는 설정 열기 | `Esc`로 상세 정보를 닫습니다. 검색창 옆의 도구 아이콘으로 설정을 엽니다. |

## 제작법과 획득처

- 제작, 요리, 3×3 변환 블록의 제작법을 확인할 수 있습니다. 재료를 클릭하면 해당 아이템을, 제작대 이름을 클릭하면 해당 제작대의 제작법을 볼 수 있습니다.
- 용도 탭에는 선택한 아이템을 사용하는 제작법이 표시됩니다. 알려진 획득처에는 전리품, 상점, 퀘스트, 계약, 낚시, 상자, 채집이 포함됩니다.
- `#Blueprints`와 같은 검색으로 제작법 설계도를 찾을 수 있습니다. `R`은 확인된 획득처, `U`는 해금되는 제작법을 표시합니다.

## 검색

아이템 이름이나 중국어 이름의 병음으로 검색할 수 있습니다. `#Accessories`는 장신구, `@vanilla`는 기본 게임 아이템을 찾습니다.

`$text`은 설명을 검색하고 `%category`는 분류를 필터링합니다. 따옴표로 구절을 묶고 `-word`로 단어를 제외합니다. 공백은 조건을 결합하고 세로줄은 둘 중 하나에 해당하는 항목을 찾습니다. 개발자 모드에서는 `id:144`처럼 ID로 검색할 수 있습니다.

## 설정, 치트 및 개발자 모드

싱글플레이에서는 자동 일시 정지가 기본으로 켜져 있으며 설정에서 끌 수 있습니다. 멀티플레이 중에는 게임이 계속됩니다.

도구 아이콘을 `Ctrl + 왼쪽 클릭`하여 치트 모드를 전환합니다. 아이템을 클릭하면 하나, Shift를 누르고 클릭하면 한 묶음을 얻습니다. 개발자 모드도 켜면 게임에서 생성할 수 있는 숨겨진 아이템을 얻을 수 있습니다.
