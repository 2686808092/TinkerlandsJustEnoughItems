# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · **Français** · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Consultez les objets, leurs recettes, leurs usages et leurs sources depuis l’inventaire de Tinkerlands. La liste des objets s’affiche à gauche.

## Installation

Téléchargez `Just_Enough_Items_1.7.4.zip` depuis [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest). Placez le ZIP tel quel dans le dossier `mods` du jeu et relancez le jeu. Retirez l’ancienne archive JEI lors d’une mise à jour.

L’interface du mod est disponible en chinois simplifié et en anglais. Les noms des objets et des postes de fabrication suivent la langue du jeu.

## Commandes par défaut

| Action | Commande |
| --- | --- |
| Voir les recettes ou les sources | Cliquez à gauche sur un objet de la liste, ou survolez l’objet et appuyez sur `R`. |
| Voir les usages | Cliquez à droite sur un objet de la liste, ou survolez l’objet et appuyez sur `U`. |
| Rechercher et changer de page | `Ctrl+F` place le curseur dans la recherche. Utilisez la molette, les flèches ou `Page Up` / `Page Down` pour changer de page. |
| Afficher ou masquer la liste | Appuyez sur `Ctrl+O` avec l’inventaire ouvert. Le mod mémorise le choix. |
| Fermer la fiche ou ouvrir les paramètres | Appuyez sur `Esc` pour fermer la fiche. Cliquez sur l’icône d’outil près de la recherche pour les paramètres. |

## Recettes et sources

- Consultez les recettes de fabrication et de cuisine ainsi que la grille de transmutation 3×3. Cliquez sur un ingrédient pour ouvrir sa fiche ou sur le nom d’un poste pour en voir les recettes.
- L’onglet des usages présente les recettes qui consomment l’objet. Les sources connues incluent le butin, les boutiques, les quêtes, les contrats, la pêche, les coffres et la collecte.
- Trouvez les plans de recettes avec une recherche telle que `#Blueprints`. `R` affiche les sources connues et `U` la recette débloquée.

## Recherche

Recherchez par nom d’objet ou en pinyin pour les noms chinois. `#Accessories` filtre les accessoires et `@vanilla` les objets du jeu de base.

`$text` recherche dans les descriptions et `%category` filtre les catégories. Les guillemets encadrent une expression et `-word` exclut un mot. L’espace combine les conditions et la barre verticale permet les alternatives. Le mode développeur accepte les recherches par ID comme `id:144`.

## Paramètres, triche et mode développeur

La pause automatique est activée par défaut en solo et peut être désactivée. La partie continue en multijoueur.

Faites `Ctrl + clic gauche` sur l’icône d’outil pour basculer le mode triche. Cliquez sur un objet pour en obtenir un, ou maintenez Maj pour obtenir une pile. En activant aussi le mode développeur, vous pouvez obtenir les objets cachés que le jeu sait générer.
