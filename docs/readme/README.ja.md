# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · **日本語** · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Tinkerlands のインベントリ画面で、アイテム、レシピ、用途、入手方法を調べられる Mod です。アイテム一覧は画面の左側に表示されます。

## インストール

[GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) から `Just_Enough_Items_1.7.2.zip` をダウンロードし、展開せずにゲームの `mods` フォルダーに入れて、ゲームを起動し直してください。更新時は古い JEI の ZIP を取り除いてください。

Mod の画面表示は簡体字中国語と英語に対応しています。アイテム名と作業台名はゲームの言語設定に従います。

## 既定の操作

| 操作 | 入力 |
| --- | --- |
| レシピ・入手方法を見る | 一覧のアイテムを左クリックするか、カーソルを重ねて `R` を押します。 |
| 用途を見る | 一覧のアイテムを右クリックするか、カーソルを重ねて `U` を押します。 |
| 検索・ページ移動 | `Ctrl+F` で検索欄に移動します。ホイール、矢印、または `Page Up` / `Page Down` でページを切り替えます。 |
| 一覧の表示切替 | インベントリを開いて `Ctrl+O` を押します。最後の状態は保存されます。 |
| 詳細を閉じる・設定を開く | `Esc` で詳細を閉じます。検索欄横の工具アイコンをクリックすると設定が開きます。 |

## レシピと入手方法

- クラフト、料理、変換ブロックの 3×3 レシピを確認できます。素材をクリックするとその詳細が開き、作業台名をクリックするとその作業台のレシピが表示されます。
- 「用途」には選択したアイテムを使うレシピが表示されます。入手方法にはドロップ、店、クエスト、契約、釣り、宝箱、採集などがあります。
- `#Blueprints` のような検索でレシピの設計図を探せます。`R` で判明している入手方法、`U` で解放されるレシピを確認できます。

## 検索

アイテム名で検索できます。中国語名にはピンインも使えます。`#Accessories` はアクセサリー、`@vanilla` は基本ゲームのアイテムに絞り込みます。

`$text` は説明文を検索し、`%category` は分類で絞り込みます。引用符で語句を囲み、`-word` で語を除外します。スペースは条件の組み合わせ、縦棒はどちらかの条件への一致です。開発者モードでは `id:144` のような ID 検索ができます。

## 設定・チート・開発者モード

シングルプレイでは既定で自動一時停止が有効です。設定で無効にできます。マルチプレイ中はゲームが進行します。

工具アイコンを `Ctrl＋左クリック` するとチートモードを切り替えられます。一覧のアイテムをクリックすると 1 個、Shift を押しながらクリックすると 1 スタック入手できます。開発者モードも有効にすると、ゲームで生成可能な隠しアイテムを入手できます。
