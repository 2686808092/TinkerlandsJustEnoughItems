# Just Enough Items for Tinkerlands

[English](README.en.md) · [简体中文](../../README.md) · [繁體中文](README.zh-Hant.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · **Español** · [Français](README.fr.md) · [日本語](README.ja.md) · [Português (Brasil)](README.pt-BR.md) · [Русский](README.ru.md)

Consulta objetos, recetas, usos y formas de obtención desde el inventario de Tinkerlands. La lista de objetos aparece a la izquierda.

## Instalación

Descarga `Just_Enough_Items_1.7.1.zip` en [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest). Coloca el ZIP sin descomprimir en la carpeta `mods` del juego y reinicia. Al actualizar, retira el ZIP anterior de JEI.

La interfaz del mod está disponible en chino simplificado e inglés. Los nombres de los objetos y estaciones siguen el idioma del juego.

## Controles predeterminados

| Acción | Control |
| --- | --- |
| Ver recetas o formas de obtención | Haz clic izquierdo en un objeto de la lista o coloca el cursor sobre él y pulsa `R`. |
| Ver usos | Haz clic derecho en un objeto de la lista o coloca el cursor sobre él y pulsa `U`. |
| Buscar y cambiar de página | `Ctrl+F` activa la búsqueda. Usa la rueda, las flechas o `Page Up` / `Page Down` para cambiar de página. |
| Mostrar u ocultar la lista | Pulsa `Ctrl+O` con el inventario abierto. El mod recuerda la elección. |
| Cerrar detalles o abrir ajustes | Pulsa `Esc` para cerrar los detalles. Abre los ajustes con el icono de herramienta junto al campo de búsqueda. |

## Recetas y obtención

- Consulta recetas de fabricación, cocina y transmutación en la cuadrícula 3×3. Haz clic en un ingrediente para consultarlo, o en el nombre de una estación para ver sus recetas.
- La pestaña de usos muestra recetas que consumen el objeto. Las fuentes conocidas incluyen botín, tiendas, misiones, contratos, pesca, cofres y recolección.
- Busca planos de recetas con una consulta como `#Blueprints`. Pulsa `R` para ver las fuentes conocidas y `U` para ver la receta que desbloquea.

## Búsqueda

Busca por nombre de objeto, o por pinyin para nombres chinos. Usa `#Accessories` para accesorios y `@vanilla` para objetos del juego base.

`$text` busca en las descripciones y `%category` filtra por categoría. Usa comillas para frases y `-word` para excluir palabras. El espacio combina condiciones y la barra vertical permite alternativas. En modo desarrollador puedes buscar por ID con `id:144`.

## Ajustes, trucos y modo desarrollador

La pausa automática está activada por defecto en partidas individuales y se puede desactivar en los ajustes. En multijugador la partida continúa.

Usa `Ctrl + clic izquierdo` en el icono de herramienta para activar o desactivar el modo de trucos. Un clic sobre un objeto da una unidad y con Mayús da una pila. Con el modo desarrollador activo también puedes obtener objetos ocultos que el juego pueda generar.
