# Just Enough Items for Tinkerlands

[English](docs/readme/README.en.md) · **简体中文** · [繁體中文](docs/readme/README.zh-Hant.md) · [한국어](docs/readme/README.ko.md) · [Deutsch](docs/readme/README.de.md) · [Español](docs/readme/README.es.md) · [Français](docs/readme/README.fr.md) · [日本語](docs/readme/README.ja.md) · [Português (Brasil)](docs/readme/README.pt-BR.md) · [Русский](docs/readme/README.ru.md)

Just Enough Items for Tinkerlands 是一款游戏内物品与配方查询模组。打开人物物品栏，即可在左侧搜索物品、查看制作方法和用途，或查询物品从哪里获得。

## 安装

在 [GitHub Releases](https://github.com/2686808092/TinkerlandsJustEnoughItems/releases/latest) 下载 `Just_Enough_Items_1.7.0.zip`，将 ZIP 原样放入 Tinkerlands 安装目录的 `mods` 文件夹，再启动游戏。升级时移除旧版 JEI ZIP，避免同时加载两个版本。

模组界面提供简体中文和英文。物品和工作站名称沿用游戏当前的译名，也支持已加载的汉化模组。

## 默认操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 查看配方或获取途径 | 左键点击列表里的物品，或悬停物品按 `R` |
| 查看用途 | 右键点击列表里的物品，或悬停物品按 `U` |
| 查看材料或工作站 | 点击配方中的材料，或点击工作站名称查看该站的配方 |
| 搜索和翻页 | `Ctrl+F` 聚焦搜索框。用滚轮、翻页按钮或 `Page Up` / `Page Down` 翻页 |
| 显示或隐藏列表 | 打开人物栏后按 `Ctrl+O`，再次按下恢复显示。模组会记住上次选择 |
| 关闭详情 | `Esc` |
| 打开设置 | 点击搜索框右侧的工具图标 |

## 配方、用途和获取途径

- **配方**显示制作所需的工作站、材料、数量和产物，涵盖普通合成、烹饪和转化方块。转化方块按九宫格显示，替代材料在同一格轮换。
- **用途**列出以当前物品为材料的配方。可直接点击材料继续查询。
- **获取途径**展示模组能从游戏数据识别的来源，例如怪物掉落、商店、任务、契约、钓鱼、宝箱和采集。
- **配方蓝图**可用 `#配方 蜂拥药水` 这类查询找出。对蓝图按 `R` 查看已识别的获取途径，按 `U` 查看它解锁的制作配方。

## 搜索

按物品名称搜索，也可以输入拼音全拼或首字母。例如 `fengmi` 和 `fm` 都可以查找“蜂蜜”。

| 示例 | 含义 |
| --- | --- |
| `#饰品` 或 `#Accessories` | 按中英文标签查找饰品 |
| `@原版 #材料` | 同时按来源和标签筛选，只看原版材料 |
| `$关键词` 或 `%类别` | 按物品描述或类别筛选 |
| `铁锭\|铜锭` | 匹配其中任一搜索词 |
| `#材料 -木` | 查找材料并排除匹配“木”的结果 |
| `id:144` | 在开发者模式下查找物品 ID 144 |

多个条件用空格连接。包含空格的词组可用双引号括起来。

## 设置、作弊和开发者模式

单人默认在打开人物栏时自动暂停，可在设置中关闭。联机时游戏继续运行。设置中还可调整快捷键和开启开发者模式。

按住 `Ctrl` 左键点击工具图标可切换作弊获取。开启后，在列表中点击物品获取一个，按住 `Shift` 点击可获取一组。设置中的开发者模式会显示更多隐藏条目，并启用 ID 搜索。两种模式同时开启时，可获取其中能由游戏生成的物品。
